# Changelog

All notable changes to this project are documented here.

## 1.0.0 - 2026-08-31

- Discover local MCP server commands for Codex, Claude Code, Cursor, and OpenCode v2.
- Correlate configured commands with macOS and Linux process trees.
- Mark old detached and zombie matches as explainable suspicions.
- Add snapshot table, watch mode, JSON schema v1, and per-PID explanations.
- Redact common secret shapes from command summaries.
- Establish a strict read-only, offline safety boundary.
